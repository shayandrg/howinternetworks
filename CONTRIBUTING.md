# Contributing to How the Internet Works

Thank you for helping make this atlas better.

## Setup

```
npm install
npm run dev
```

## Before you submit a pull request

1. Run `npm run check` (lint, typecheck, test, build).
2. Run `npm run originality` to confirm no text was copied.
3. Play every step of your topic in both Simple and Technical modes and in both Network and Sequence views.

## Content rules (summary)

- `simple`: one or two sentences, at most 220 characters, everyday words.
- `technical`: at most 700 characters, precise message names, flags, ports, sizes.
- Step title: sentence case, at most 32 characters, start with a verb when possible.
- Tagline: at most 60 characters.
- Every fact must trace to an RFC or official spec listed in `sources`.
- Write in your own words. Never copy from the research pack or any other site.

See [docs/CONTENT-GUIDE.md](docs/CONTENT-GUIDE.md) for the full guide.
